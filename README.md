# landing-page-practica

Bocado es una landing page para una dulcería ficticia de Santiago. Abre `index.html` en tu navegador para recorrer el sitio.

El catálogo, las promociones y la bolsa funcionan con HTML, CSS y JavaScript. La bolsa guarda la selección en el navegador cuando el almacenamiento local está disponible. Los precios y el correo de contacto son de demostración.
