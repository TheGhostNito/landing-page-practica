# Vector · Ingeniería digital

Landing page en español para un estudio ficticio de ingeniería digital. El diseño sigue el estilo Swiss con una retícula de líneas finas, tipografía Helvetica Neue y azul Klein.

Abre `index.html` en un navegador para ver la página. Funciona con HTML, CSS y JavaScript, sin instalación ni servidor. Las consultas se preparan en el navegador y se pueden descargar como archivos de texto.

## Imágenes

Las dos imágenes se crearon con la herramienta integrada ImageGen y se optimizaron en formato WebP.
